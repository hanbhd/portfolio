# Portfolio

Dieses Repository enthält den Quellcode meines persönlichen Bewerbungsportfolios.

Das Portfolio wurde mit Angular, TypeScript, HTML und CSS entwickelt. Ziel war es, eine übersichtliche und klar strukturierte Anwendung zu erstellen, die meine Arbeitsweise und ausgewählte Projektbeispiele zeigt.

Bei der Umsetzung habe ich auf eine nachvollziehbare Struktur, verständliche Benennung und eine saubere Aufteilung in eigenständige Komponenten geachtet.

## Verwendete Technologien

- Angular
- TypeScript
- HTML
- CSS

## Projektzweck

Dieses Projekt wurde als persönliches Bewerbungsportfolio entwickelt. Es dient dazu, einen Einblick in meine Arbeitsweise sowie in ausgewählte Frontend-Projekte zu geben.
